# 08 — Voice & AI Logic

## Voice Pipeline (V1 — Free)
```
User holds voice button
        ↓
Web Speech API listens
        ↓
Transcript sent to backend
        ↓
Backend builds context packet
        ↓
Sent to Claude API
        ↓
Claude responds with text
        ↓
Web Speech Synthesis speaks response
        ↓
Response also shown as text
```

## Voice Pipeline (V2 — Production)
```
User holds voice button
        ↓
Whisper API converts speech to text
        ↓
Backend builds context packet
        ↓
Claude API processes
        ↓
ElevenLabs converts response to audio
        ↓
Audio streamed to user
```

## Buddy Personality Rules

### Always:
- Warm, supportive, never judgmental
- Speak like a trusted senior trader friend
- Reference past context naturally — never directly
- Celebrate wins genuinely
- Address losses with empathy first, analysis second

### Never:
- Never say "I remember you said..."
- Never say "According to your data..."
- Never reference specific personal details directly
- Never give financial advice or signals
- Never be robotic or formal
- Never make trader feel surveilled

### Example — Good vs Bad memory reference:
```
Bad:  "You mentioned your wife is sick"
Good: "How's everything at home? 
       Hope things are getting better"

Bad:  "Your data shows you revenge trade"
Good: "Two losses in a row — 
       might be worth taking a breath 
       before the next one"
```

## Proactive Trigger Logic

### News Trigger
```
IF news_event.time_until <= 15 minutes
AND news_event.impact == "high"
THEN buddy speaks:
"Hey, [name] — [event] drops in [time]. 
 Your last 3 [event] sessions were mixed. 
 Worth being cautious."
```

### Loss Limit Trigger
```
IF daily_pnl <= (max_daily_loss * 0.75)
THEN buddy speaks:
"You're getting close to your daily limit. 
 [amount] left. Want to call it here?"
```

### Overtrading Trigger
```
IF trades_today >= (max_trades * 0.8)
THEN buddy speaks:
"[X] trades in — [Y] left on your limit. 
 How are you feeling?"
```

### Revenge Trade Detection
```
IF last_2_trades.result == "loss"
AND new_trade_gap_minutes <= 5
THEN buddy speaks:
"Two in a row going the wrong way. 
 What's the plan here — 
 is this still your setup?"
```

### Break Reminder
```
IF session_duration_hours >= 3
AND no_break_taken
THEN buddy speaks:
"You've been at this for [X] hours. 
 Ten minutes away from the screen 
 might be the best trade you make today."
```

### Perfect Execution
```
IF execution_score >= 9
AND followed_plan == true
THEN buddy speaks:
"That was textbook. 
 Exactly how it's supposed to be done."
```

## Memory Strategy (Mem0)

### What Gets Stored:
```
After every trade:
- Emotion + context
- Rule violations
- Execution quality
- Market conditions

After every conversation:
- Personal details mentioned
- Goals mentioned
- Concerns mentioned
- Achievements

Weekly:
- Performance patterns
- Psychology trends
- Rule compliance rate
```

### What Gets Retrieved:
```
Before every conversation:
- Top 5 most relevant memories
- Today's session context
- Recent patterns
- Personal details relevant to current context
```
