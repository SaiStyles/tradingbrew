# 11 — Metrics & KPIs

## North Star Metric
**Daily Active Users (DAU)**
A trader who opens TradingBrew daily is a retained trader.
Everything optimises for this one number.

---

## Core Metrics

### Activation
- Metric: Trader logs first trade within 24hrs of signup
- Target: 60%+ activation rate

### Retention
- Metric: Trader active 3 out of 5 trading days per week
- Target: 70%+ weekly retention at month 2

### Engagement
- Metric: Average session length
- Target: 10+ minutes per trading day

### Voice Usage
- Metric: % of trades logged via voice
- Target: 80%+ (voice is the core experience)

### Memory Depth
- Metric: Average memories stored per user at 30 days
- Target: 50+ memories (shows deep usage)

---

## Weekly Review Checklist
```
□ DAU this week vs last week
□ New signups
□ Churn (who stopped using it)
□ Most used features
□ Least used features
□ Voice usage rate
□ Average trades logged per user
□ Any bugs reported
```

---

## Red Flags
- DAU drops 20%+ week over week → investigate immediately
- Voice usage below 50% → onboarding problem
- Activation below 40% → first time experience broken
- Average session under 3 minutes → buddy not engaging enough
