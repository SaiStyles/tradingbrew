# 09 — Business Logic

## Pricing Strategy

### Launch Phase (V1)
```
100% Free
No credit card required
All features available
Goal: Build 500+ loyal users
```

### V2 Pricing (After product-market fit)
```
Free Tier:
- 30 trades/month
- Basic journaling
- News alerts
- 7 day memory

Pro ($24/month):
- Unlimited trades
- Full AI buddy
- Deep memory (unlimited)
- Psychology insights
- Prop firm monitor
- Weekly summaries
- Priority support

Elite ($59/month):
- Everything in Pro
- Multi account support
- Advanced analytics
- Custom buddy personality
- Early access to features
```

---

## Subscription Rules
- Free tier resets monthly
- Pro/Elite billed monthly or annually (20% discount)
- No refunds after 7 days
- Cancel anytime
- Data retained 90 days after cancellation
